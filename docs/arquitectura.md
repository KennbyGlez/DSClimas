# DS Climas CRM

## Objetivo

Sistema CRM para administración de clientes, sucursales, equipos HVAC, cámaras frigoríficas, órdenes de servicio y reportes técnicos.

## Tecnologías

- Flutter
- Riverpod
- GoRouter
- Drift (SQLite)
- PDF
- Signature
- Image Picker

## Arquitectura

Feature First + Repository Pattern
